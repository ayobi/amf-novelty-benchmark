# Protocol v3 locks

Protocol v3 is the locked test of the amfsplit rule changes R1 to R8. It stays a draft until its
protocol lock, when it is exported here as `PROTOCOL_v3.md` and hashed into `protocol_hashes.txt`
with the arm code and the predictions. The set lock adds the confirmation set's manifests and the
power check, before any confirmation sequence is cut.

**Correction, 4 November 2026.** The first protocol lock (commit a826ad0, tag protocol-v3-lock) committed a copy of the lock script as `PROTOCOL_v3.md`. The script took the newest file in the downloads folder whose name matched `*rotocol*v3*.md`, and that was a copy of the script itself, `lock_protocol_v3.md`. So the `eligibility_rules.md` extracted from it, and the hashes of both files, were wrong too. protocol-v3-lock.1 replaces those two files with the protocol's own export and its eligibility rules, and their two lines in `protocol_hashes.txt`. Every other line there (the predictions, the inputs, the arm code at amfsplit fa3404f, the v0.1 commit) was checked again and is unchanged. The correction came before the set lock, so before any confirmation sequence was cut. The tag protocol-v3-lock stays on a826ad0 as the record of the error.
