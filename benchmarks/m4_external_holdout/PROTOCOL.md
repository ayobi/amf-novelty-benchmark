# M4 external-LSU holdout protocol

Frozen before viewing external-deletion placement results, 29 September 2026.

1. Keep the M2b species-clade rule, 0.95 cumulative LWR compatible sets (including cutoff ties), >=90% retained query bases, training-culture intersection-if-nonempty/otherwise-union sets, VT/SH training, and Phase 4 D1/D2/novelty thresholds unchanged. The included frozen M2b code and inputs are hash-bound.
2. Primary test: 37 named-species exclusions. Remove all V18 records carrying the target's exact name or explicitly documented equivalent name, and remove every culture of that species and co-cultured lineages from the culture bridge. Ambispora callosa is already absent by label and is a separate no-deletion stratum; absence by label is not proof of biological absence under all mislabeled accessions.
3. Secondary test: 15 frozen-genus exclusions, including unnamed cultures in the genus. Canonical genus mappings follow the frozen project. Keep these scores separate from species holdouts. These are nomenclature-based exclusions, not a claim that every named genus is monophyletic.
4. Prune the removed tips from the published topology. For actual deletion folds, realign the remaining raw external sequences from scratch with MAFFT --localpair --maxiterate 1000 --threadit 0. Refit branch lengths and GTR+G4 parameters using only retained references. The inherited published topology is a conditional backbone; no de novo tree or new bootstrap support is claimed.
5. Add all 903 raw query windows to each fixed fold alignment using MAFFT --auto --addfragments --keeplength --mapout. Verify every reference column remains unchanged. Re-place training and held-out copies alike; never reuse tree-edge IDs or old training placements across different trees. Query names/classes do not enter reference alignment/model fitting.
6. EPA-ng evaluates every edge, without pre-masking, retaining all output weights at 12-decimal precision. Build clade units anew for each fold. Taxonomic calls come from that fold's eligible training-culture holders, not directly from a reference tip name.
7. The already-absent species reuses the frozen full-reference placement as an exact negative-deletion control. It is not counted as a successful tip-removal experiment. For genus folds, compute a matched full-V18 culture-bridge control with the same excluded cultures; species controls reproduce the existing M2b species-holdout rows exactly.
8. Report paired per-copy calls, false-known rates (copies, species/culture macro averages), genus-call correctness/coverage, novelty rank, and short/same-length divergent-copy behavior. Keep genuine deletion and already-absent strata separate. Do not silently combine partial runs into a complete benchmark.
9. Pilot chosen before new outcomes: Glomus chinense, one member of an already identified unresolved pair. Run the Ambispora callosa no-deletion control too. Pilot selection is targeted development, not random or independent validation.
10. The three prior known-species demotions and the three sister-species pairs receive descriptive audits only. Do not change thresholds, culture labels, aggregation rules, or species-complex rules in response to these scores.
11. VT and SH external databases remain fixed; this is external LSU/V18 plus culture-bridge exclusion, not a full all-marker external-reference purge. The cohort has already been used for development. Independent culture validation requires new, verified material; environmental reads alone do not supply species truth or proof of a divergent paralog.
12. Preserve completed stages with input/configuration/output hashes. Failed or incomplete stages cannot count as completed folds. Provide a resumable PC runner and compact evidence export. Original M2b files and results stay available.
